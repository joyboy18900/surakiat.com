นี่คือบทความตัวอย่างแรกของเว็บไซต์เวอร์ชันใหม่ ที่สร้างด้วย VitePress แทนไฟล์ HTML
แบบเดิม เนื้อหาทั้งหมดตอนนี้เขียนด้วย Markdown ธรรมดา และหน้าตาของเว็บไซต์ยังคง
เหมือนเดิมทุกอย่าง

ลิงก์ภายในข้อความ เช่น [ลิงก์นี้](/) จะได้สีของ accent โดยอัตโนมัติ ส่วน
`inline code` จะมีกรอบและใช้ฟอนต์ monospace เพื่อให้อ่านง่ายบนพื้นหลังสีเข้ม

## หัวข้อย่อย

ตัวอย่างโค้ดยาว ๆ จะถูกจัดวางในกรอบแยกต่างหาก แทนที่จะแทรกอยู่ในบรรทัดเดียวกับ
ข้อความ เพื่อให้อ่านง่ายแม้ว่าจะยาวแค่ไหนก็ตาม:

```js
function greet(name) {
  return `สวัสดี, ${name}`;
}

console.log(greet('surakiat'));
```

(เนื้อหาโพสต์ตัวอย่าง สามารถแก้ไขแทนที่ด้วยงานเขียนจริงได้เลย)
