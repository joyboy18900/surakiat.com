This is the first sample post on the new version of this site, built with
VitePress instead of the old plain HTML files. All content is now written
in plain Markdown, and the site's look stays exactly the same.

Inline links like [this one](/) automatically pick up the accent color,
and `inline code` gets a bordered, monospace treatment so it stays readable
against the dark background.

## A subheading

Longer code samples drop into a bordered block instead of running inline,
so they stay legible even when they wrap:

```js
function greet(name) {
  return `Hello, ${name}`;
}

console.log(greet('surakiat'));
```
